The published app

Subscription Sentinel helps organize recurring payments and surface upcoming renewals. I built and shipped the iOS app, working across receipt import, reminders, native interface flows and release preparation.

Receipt import & fallbacks

The local receipt-import implementation combines Vision OCR with structured on-device model extraction when supported. Heuristic parsing handles devices without the model and cases where extraction fails.

Native iOS implementation

The development work spans native data storage and notification scheduling, with attention to upcoming renewal dates and the system’s notification budget. The App Store link opens the currently published product; the on-device extraction pipeline describes the local development implementation.
