FMGate — Receipt Extraction

A technical prototype exploring how OCR, rules and structured on-device extraction can turn receipt text into reviewable fields.

My rolePrototype development & evaluation
Project statusPaused technical prototype
Built with / FocusSwift · Vision OCR · Foundation Models

Validate before expanding

The project asks whether receipt data can be extracted reliably enough to justify a larger document product. I built around a small, explicit set of fields and an evaluation workflow, rather than treating model output as automatically correct.

A baseline and a model route

The implementation includes Vision OCR, text-line processing, rule-based amount/date parsing, structured receipt fields and a Foundation Models integration path. Small-sample baseline checks helped identify which fields were easier or harder to recover.

Current stage

The initial prototype was paused. A completed model-versus-baseline comparison and a released document-management app are not claimed here.
