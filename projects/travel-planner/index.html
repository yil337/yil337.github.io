Travel Planner

A web travel-planning prototype that organizes places of interest into rule-based itineraries, with a San Diego fallback dataset.

Planning flow

The application combines a Flask web interface, point-of-interest service wrappers and rule-based itinerary organization. Local fallback data supports the planning flow when external place data is unavailable.

Project scope

The related Travel and travel-planning folders represent versions of one project. The external APIs and a public deployment have not been revalidated, so this is presented as a local software prototype.
