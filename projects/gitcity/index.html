GitCity

A repository explorer that turns files and Git history into a 3D city. Browse directories, select buildings, inspect changes and move through commits.

Repository to city

A Node.js analyzer reads local Git objects and reconstructs first-parent snapshots. Directories become districts and files become buildings, with logarithmic building heights representing text line counts.

History and navigation

The current prototype has 3D and plan views, directory navigation, search, file selection and a commit timeline. Fixed plots help viewers follow files as they are added, changed, renamed or removed.

Current version

The latest local iteration includes synthetic Shoreline and public Click examples, guided history stops, animated transitions and PNG export with metadata and a legend.

Scope

This remains an evolving local project. The current version does not include a full branch graph, live workspace monitoring, dependency analysis or video export. Earlier PhantomCity and night-city versions are part of the same project history.
