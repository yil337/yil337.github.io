Understand a repository as a whole

GitCity explores a spatial way to read code structure and change. Directories and files keep stable identities so that navigation and comparison can share the same frame of reference. I work on the product direction, interaction and implementation.

Structure, history and details

The current Repository Atlas prototype uses Vite and Three.js, with Plan and 3D views, file selection, first-parent Git comparisons, rename handling, inline diffs and PNG export. The aim is to connect the overall shape of a repository to the changes a developer needs to inspect.

Iteration and scope

This remains a local tool in active development. The current implementation and earlier PhantomCity/night-city experiments are stages of the same project; features from different versions should not be assumed to exist together. The gallery preserves earlier visual work.
